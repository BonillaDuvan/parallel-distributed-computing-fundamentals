## Compilar

Con GCC:

```bash
gcc -std=c11 -Wall -Wextra -pedantic classes/ce_01_primos_arreglo.c -o ce_01
```

Ejecutar en Windows:

```bash
.\ce_01.exe
```

Repetir cambiando el nombre del archivo para cada ejercicio.
